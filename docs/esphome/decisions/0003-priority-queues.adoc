= HACAN-ESP-ADR-0003: Use compile-time bounded queues per traffic class

Status: *Accepted*

== Context

The protocol requires bounded transmit queues and reports queue drops, but does
not prescribe an implementation queue layout. One shared queue would allow
management traffic such as heartbeats to evict commands, events, or states.

== Decision

Use fixed `std::array` storage for separate control, event, state/query,
management, and diagnostic queues. The initial implementation uses a capacity
of eight frames for each queue. Drain higher CAN priorities first. A queue
cannot evict entries in another class. Only unsent state for the same endpoint
may be coalesced.

== Consequences

Memory use is deterministic without heap allocation. Commands and events
retain their individual occurrences. Per-firmware YAML queue capacities remain
an intentionally deferred enhancement; adding them must preserve the separation
between traffic classes. This is an ESPHome implementation policy, not a
change to the HACAN wire protocol.

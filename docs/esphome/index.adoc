== Scope of the first implementation step

The first step provides a standalone C++ protocol library, the base `hacan:`
ESPHome component, and two endpoint profiles. The library encodes, decodes,
and validates every message kind defined by protocol version 1. The base
component provides node lifecycle, commissioning, entity directory behavior,
and bounded transmit queues.

`binary_sensor: platform: hacan` publishes a local bistable input as
`STATE<bool>`. `switch: platform: hacan` owns a local binary output, accepts
`COMMAND<bool>`, and publishes `STATE<bool>` after each applied change.
Additional endpoint profiles remain deferred.

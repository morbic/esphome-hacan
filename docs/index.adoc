= HACAN
:toc: left
:sectnums:

HACAN (Home Automation over CAN) is a draft protocol and implementation
foundation for distributed home automation over CAN.

== Documentation

* xref:protocol/index.adoc[Protocol specification]
* xref:protocol/architecture.adoc[Protocol architecture]
* xref:protocol/decisions/index.adoc[Protocol decision records]
* xref:esphome/index.adoc[ESPHome implementation]

== Status

The architecture decisions for the version 1 baseline are accepted. The
protocol remains a draft until its first implementation is validated in a
representative physical installation.
